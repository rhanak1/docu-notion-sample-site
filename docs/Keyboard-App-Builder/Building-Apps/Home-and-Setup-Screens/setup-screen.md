# Setup Screen {#21480858a4b68175aa76ec9b9e9bebf9}


The Setup screen is shown after the user taps the **Set Up Keyboard** button on the Home screen. It contains some introductory text and then two or three steps.


![](/notion_imgs/setup-screen.21480858-a4b6-812a-9735-f13cdab4e48c.png)


![](/notion_imgs/setup-screen.21480858-a4b6-81b9-9459-e007aa1e01b5.png)


Whether you see two or three steps will depend on how many keyboards you have added to the app:


| **Only one keyboard layout**                                | **More than one keyboard layout**                                                           |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| **Step 1:** Enable keyboard<br/>**Step 2:** Change keyboard | **Step 1:** Choose keyboard<br/>**Step 2:** Enable keyboard<br/>**Step 3:** Change keyboard |


To configure the image and text on the Setup screen, select **Screens** from the tree view on the left of the KAB program window and select the **Setup Screen** tab. Follow the instructions on the screen.


_**Choose Keyboard**_


When the user taps the **Choose Keyboards** button, the Choose Keyboards screen will appear. One or more keyboards should be chosen.


For example, in the image below, the app allows the user to choose between a QWERTY and an AZERTY keyboard layout.


![](/notion_imgs/setup-screen.21480858-a4b6-818a-a518-e43072a09f6e.png)


![](/notion_imgs/setup-screen.21480858-a4b6-81a0-b1de-dfffea499ec4.png)


_**Enable Keyboard**_


When the user taps the **Enable Keyboard** button, the phone’s **Manage keyboards** screen will appear. They need to tap on the new keyboard to enable it.


When they do this, Android will warn them that this input method could be dangerous. They should not worry: a Keyman keyboard does not collect any personal data.


![](/notion_imgs/setup-screen.21480858-a4b6-8122-8a27-fb7f06d4ea21.png)


![](/notion_imgs/setup-screen.21480858-a4b6-81a1-aed7-dd5f86b2cd56.png)


_**Change Keyboard**_


When the user taps the **Change Keyboard** button, the phone’s **Change Keyboard** dialog box will appear. They need to tap on the new keyboard to make it the current one.


![](/notion_imgs/setup-screen.21480858-a4b6-815c-96ca-fbe2845bad24.png)


![](/notion_imgs/setup-screen.21480858-a4b6-8192-9847-de95e238eaf3.png)


After completing each of the two or three steps, the keyboard is ready to be used in other apps such as WhatsApp, Gmail and Facebook.
